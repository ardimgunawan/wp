Cara Isi Saldo WP via QRIS

  1. Request tiket pembelian saldo seperti via transfer bank.
  2. Copy jumlah nominal transfer yang diminta.
  3. Lakukan pembayaran ke QRIS Server Pulsa WP sesuai jumlah nominal tiket.
  4. Konfirmasi pembayaran ke CS agar saldo dapat diinput.
NOTE : HANYA BISA UNTUK NOMINAL TIKET KURANG DARI 2.000.000
