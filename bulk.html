CARA CUAN TRANSAKSI TELKOMSEL DATA BULK


Telkomsel bulk makin cuan transaksinya kalau pakai sistem tagihan/postpaid, karena ada fee atau cashbacknya.

Prinsipnya sama dengan melakukan pembayaran tagihan BPJS atau PLN dll, yaitu dengan melakukan cek harga dulu baru kemudian melakukan transaksi pembayaran.

Berikut daftar produknya :

Kode untuk cek :

  • CEKTDZ4 = CEK 4GB+1GB OMG 30hr
  • CEKTDZ6 = CEK 6GB+2GB OMG 30hr
  • CEKTDZ10 = CEK 10GB+2GB OMG 30hr
  • CEKTDZ15 = CEK 15GB+2GB OMG 30hr
  • CEKTDZ30 = CEK 30GB+2GB OMG 30hr
  • CEKTDZ60 = CEK 60GB+2GB OMG 30hr

Kode untuk bayar :

  • BYRTDZ4 = Data 4GB+1GB OMG 30hr
  • BYRTDZ6 = Data 6GB+2GB OMG 30hr
  • BYRTDZ10 = Data 10GB+2GB OMG 30hr
  • BYRTDZ15 = Data 15GB+2GB OMG 30hr
  • BYRTDZ30 = Data 30GB+2GB OMG 30hr
  • BYRTDZ60 = Data 60GB+2GB OMG 30hr

Cara Transaksinya:

Lakukan Cek Harga :
#Kirimkan perintah cek harga menggunakan kode cek harga ke nomor yang mau diisi paket :

Contoh:
CEKTDZ4.082111186631.1234
Pesan dikirim ke center transaksi

Jika transaksi menggunakan aplikasi WP Trx, masuk menu Transaksi, pilih Telkomsel Bulk Postpaid, kemudian pilih produk Cek.

Anda akan mendapatkan balasan:
WP Trx # Boss *WP Trx* CEKTDZ4 ke: 082111186631 SUKSES. SN/Ref: Harga dasar:35000 NO 082111186631,simPATI. Saldo Rp. 0 - 0 = 0 @23/03 15:08 # :: Max komplain trx 5 hari. Trims Bossku.

Dari balasan transaksi tersebut, kita bisa tahu bahwa harga resmi atau harga operator untuk paket 4GB ke nomor 082111186631 adalah Rp 35.000.
Harga jual ke konsumen Anda dapat tentukan sendiri.


Lakukan Transaksi Bayar / Pembelian :
#Kirimkan perintah pembayaran / pembelian menggunakan kode bayar ke nomor yang mau diisi paket :

Contoh:
BYRTDZ4.082111186631.1234
Pesan dikirim ke center transaksi

Jika transaksi menggunakan aplikasi WP Trx, masuk menu Transaksi, pilih Telkomsel Bulk Postpaid, kemudian pilih produk Bayar.

Saldo saya akan terpotong berapa?
Saldo Anda akan terpotong :
Harga dasar paket + Harga produk bayar.

Misal : Harga BYRTDZ4 adalah -1.000

Maka saldo yang terpotong adalah : 35.000 + (-1.000) = 34.000

**CATATAN PENTING:

  • Harga ditentukan berdasarkan posisi nomor berada (deteksi melalui BTS).

  • Jika transaksi produk Cek Harga GAGAL dan keterangan tujuan salah, artinya nomor tidak bisa membeli paket bulk ini. Kemungkinan nomor tidak terdeteksi BTS atau usia kartu <60 hari atau sebab lainnya
