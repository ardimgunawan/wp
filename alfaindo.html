CARA DEPOSIT SALDO DI SERVER PULSA WP MELALUI INDOMARET, ALFAMART (Jalur Mitra Shopee)

LANGKAH 1 :
#BUKA APP WP TRX, MASUK MENU AGEN :

Pada bagian Deposit via Outlet, pilih outlet yg akan digunakan.

Pilih produk TOPUPALFA atau TOPUPINDO lalu masukkan nominal deposit yang diinginkan.

Atau dengan kirim pesan : TOPUPALFA.NOMINAL DEPOSIT.NOMOR TERDAFTAR / ID AGEN.PIN.

Contoh : TOPUPALFA.25000.0812345678.1234 atau TOPUPINDO.30000.WP001.1234

Anda akan mendapatkan balasan:
WP # Request deposit 50000 via Alfamart Sukses.
Tunjukkan kode pembayaran APCM69L6GPDUG5 untuk deposit Mitra Shopee ke kasir dengan jumlah bayar 50000. Berlaku 10 jam.

Saldo akan masuk otomatis sesuai jumlah bayar, tanpa perlu konfirmasi..


LANGKAH 2 :
#PEMBAYARAN MELALUI MERCHANT :

Silahkan ke Indomaret/Alfamart di daerah Anda, langsung menuju ke kasir dengan menyebutkan ingin Top up MITRA SHOPEE dengan Kode pembayaran (Hanya Contoh) "APCM69L6GPDUG5",

Untuk berjaga-jaga, jangan lupa untuk minta struk yang tertera nomor referensi / ID transaksi ke kasir.
