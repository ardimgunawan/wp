1. Apa itu FileBrowser Quantum

FileBrowser Quantum adalah aplikasi manajemen file berbasis web yang memungkinkan komputer Windows menjadi cloud storage pribadi. File dapat diakses melalui browser dari jaringan lokal maupun internet.

  • UI modern
  • Multi user
  • WebDAV
  • Office Editor
  • Ringan

2. Persiapan

Disarankan struktur folder:

├── data
├── database

3. Download, Install & Konfigurasi Awal

  1. Download FileBrowser Quantum dari sumber resmi/proyek yang Anda gunakan.
  2. Ekstrak ke C:\FileBrowserQuantum.
  3. Jalankan executable FileBrowser Quantum.
  4. Buka browser ke alamat yang ditampilkan, misalnya http://localhost:8080.
  5. Login menggunakan akun default (sesuai dokumentasi versi yang digunakan), lalu segera ubah password administrator.
  6. Atur folder penyimpanan utama ke folder data.
  7. Buat akun pengguna jika diperlukan.
Gunakan password administrator yang kuat dan nonaktifkan akun default jika memungkinkan.

4. Setup Akses dari Internet

Metode 1 - Tailscale (Paling Mudah)

  1. Install Tailscale di komputer server.
  2. Login menggunakan akun Tailscale.
  3. Install Tailscale pada perangkat lain.
  4. Akses FileBrowser menggunakan IP Tailscale, misalnya 100.x.x.x:8080.

Kelebihan: Sangat aman, tanpa port forwarding.

Metode 2 - Cloudflare Tunnel

  1. Memiliki domain yang sudah menggunakan Cloudflare.
  2. Install cloudflared.
  3. Login ke Cloudflare.
  4. Buat Tunnel.
  5. Hubungkan hostname ke http://localhost:8080.
  6. Uji akses melalui domain.

Kelebihan: Bisa diakses publik menggunakan domain tanpa membuka port router.

5. Membuat Service Otomatis Saat Windows Startup

Metode yang direkomendasikan adalah menggunakan NSSM.

  1. Download NSSM.
  2. Jalankan nssm install.
  3. Pilih executable FileBrowser Quantum.
  4. Isi Startup Directory.
  5. Klik Install Service.
  6. Buka Services dan jalankan service.
  7. Set Startup Type menjadi Automatic.
services.msc
Sekarang FileBrowser Quantum akan otomatis berjalan setiap kali Windows menyala tanpa perlu login terlebih dahulu.
